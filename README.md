## 📖 About The Project

O projeto consiste em um componente visual de preview para NFTs, apresentando informações como:

* Imagem da coleção
* Nome do NFT
* Valor em Ethereum
* Tempo restante
* Informações do criador

O desafio foi excelente para praticar:

* Estruturação de componentes
* Efeitos de overlay
* Hover interactions
* Organização visual
* Responsividade
* Design moderno com CSS

---

✅ Card NFT moderno e responsivo
✅ Overlay com efeito hover na imagem

## 🧠 What I Learned

Durante esse projeto pratiquei conceitos importantes como:

* Criação de overlays com `position: absolute`
* Controle de estados com `:hover`
* Uso de variáveis CSS com `:root`
* Estruturação de componentes reutilizáveis
* Alinhamento com Flexbox
* Aplicação de sombras e profundidade visual
* Melhor organização de estilos modernos
